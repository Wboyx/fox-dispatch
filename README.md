# 🛰 Fox Dispatch

سرور ایران تسک ثبت می‌کند، گیت‌هاب اجرا می‌کند.

## مسئله

```text
۱. خیلی از سرویس‌ها از ایران در دسترس نیستند
۲. قانون قرمز: کار سنگین و ترافیک کاربر نباید روی سرور ایران باشد
```

## راه‌حل

جهت را برعکس می‌کنیم. سرور ایران فقط یک فایل JSON در این مخزن می‌گذارد. رانر گیت‌هاب که خارج از ایران است بیدار می‌شود، کار را انجام می‌دهد و نتیجه را برمی‌گرداند.

```text
سرور ایران  ──ثبت تسک──▶  مخزن گیت‌هاب
                              │
                        GitHub Actions اجرا می‌کند
                              │
سرور ایران  ◀──نتیجه──────────┘
```

هیچ درخواست فیلترشده‌ای از ایران زده نمی‌شود.

## چرا رایگان است

```text
مخزن عمومی  ->  دقیقه‌های GitHub Actions نامحدود
Artifact     ->  ۳۰ روز نگهداری خروجی
```

## استفاده

روی سرور:

```bash
export GITHUB_TOKEN=...
python3 client/foxtask.py submit probe --title "تست دسترسی" --url https://huggingface.co/
python3 client/foxtask.py wait <id>
python3 client/foxtask.py runs
```

## انواع تسک

| نوع | کار |
|---|---|
| `probe` | بررسی دسترسی از بیرون ایران |
| `fetch` | دریافت فایل از دامنه مجاز |
| `ffmpeg` | پردازش ویدیو |
| `assemble` | چیدمان چند کلیپ |

جزئیات در `docs/TASK_SCHEMA.md`.

## امنیت

```text
مخزن عمومی است، پس هیچ داده شخصی اینجا نمی‌آید
تسک قبل از ارسال و قبل از اجرا برای الگوی Secret اسکن می‌شود
fetch فقط از دامنه‌های runner/allowlist.txt مجاز است
این یک پل کنترلی است، نه پروکسی عمومی
ترافیک کاربر نهایی از این مسیر عبور نمی‌کند
```

## سازگاری با قانون قرمز

جهت جریان:

```text
Bot روی سرور ایران  ->  GitHub API  ->  رانر خارج از ایران
```

فقط درخواست کنترلی خود سرویس. هیچ پورت ورودی باز نمی‌شود و هیچ کاربری از سرور ایران خارج نمی‌شود.

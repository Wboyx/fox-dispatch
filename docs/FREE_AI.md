# فهرست هوش مصنوعی رایگان

همه موارد این فهرست بدون کارت بانکی‌اند. بیشترشان فقط ایمیل می‌خواهند.

## اولویت‌بندی برای پروژه ما

### پله ۱ — همین حالا و بدون حساب جدید

```text
GitHub Models    با همان توکن گیت‌هاب فعلی
                 تنها گزینه‌ای که از ایران هم مستقیم در دسترس است
Pollinations     تولید تصویر بدون هیچ کلیدی
```

### پله ۲ — یک ثبت‌نام ایمیلی، بیشترین سود

```text
Cloudflare       ۱۰ هزار نورون روزانه: حدود ۲۳۰ تصویر + Whisper + متن
Hugging Face     سهمیه GPU روزانه برای ویدیو
Groq             سریع‌ترین متن + ۲۰۰۰ تبدیل صدا به متن در روز
```

### پله ۳ — برای حجم و تنوع

```text
Cerebras     حدود ۱ میلیون توکن در روز
Gemini       ۱۵۰۰ درخواست در روز، زمینه بلند
OpenRouter   یک کلید، ده‌ها مدل، برای نظر دوم
Mistral      حجم ماهانه بالا
NVIDIA NIM   حدود ۱۰۰۰ درخواست
```

## نقشه استفاده در خانواده فاکسی

| کار | ارائه‌دهنده | فاکسی |
|---|---|---|
| تحلیل لاگ سرور | GitHub Models یا Groq | فاکسی ۱ |
| نوشتن و بهبود پرامپت | Cerebras یا Gemini | فاکسی ۰ |
| فریم کلیدی ویدیو | Cloudflare FLUX | فاکسی ۶ |
| تولید ویدیو | Hugging Face | فاکسی ۶ |
| تبدیل صدا به متن | Groq Whisper | فاکسی ۶ |
| تقسیم و مسیریابی کار | همه، با چرخش | فاکسی ۷ |

## قانون چرخش

```text
۱. کار را به ارزان‌ترین ارائه‌دهنده‌ای بده که از پسش برمی‌آید
۲. سهمیه هر کدام جدا شمرده می‌شود
۳. اگر یکی تمام شد، به بعدی برو و به کاربر بگو
۴. ساخت حساب اضافی برای دور زدن سقف ممنوع است
```

## هشدار کهنگی

سهمیه‌ها و مدل‌ها سریع عوض می‌شوند. هیچ عددی از این فایل بدون تأیید تازه، مبنای تصمیم نیست.

```bash
python3 client/foxtask.py submit probe --title "تست ارائه‌دهنده‌ها" --url ...
```

## کلیدها کجا نگهداری می‌شوند

```text
هرگز در چت، هرگز در تسک، هرگز در مخزن
فقط در Secrets مخزن fox-dispatch
Settings > Secrets and variables > Actions
```

نام‌های استاندارد:

```text
HF_TOKEN
GROQ_API_KEY
CEREBRAS_API_KEY
GEMINI_API_KEY
OPENROUTER_API_KEY
MISTRAL_API_KEY
CF_ACCOUNT_ID  و  CF_API_TOKEN
```
